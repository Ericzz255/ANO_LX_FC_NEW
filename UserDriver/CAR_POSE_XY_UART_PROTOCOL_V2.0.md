# 小车单片机 X/Y → 无线透传 → 飞控 UART 协议 V2.0

小车上的单片机负责输出完整14字节帧；无线模块只做透明传输，飞控从USART1接收原始帧。

## 串口

```text
115200 bit/s
8-N-1
无流控
20 Hz
3.3 V TTL
```

## 固定14字节帧

| 偏移 | 长度 | 字段 |
|---:|---:|---|
| 0 | 1 | `0xAA` |
| 1 | 1 | `0x55` |
| 2 | 4 | `X_MM`，有符号32位小端 |
| 6 | 4 | `Y_MM`，有符号32位小端 |
| 10 | 2 | CRC16，小端 |
| 12 | 1 | `0x0D` |
| 13 | 1 | `0x0A` |

CRC采用CRC-16/CCITT-FALSE：

```text
Poly   = 0x1021
Init   = 0xFFFF
RefIn  = false
RefOut = false
XorOut = 0x0000
覆盖范围 = frame[2]...frame[9]
```

正常坐标单位为毫米。无有效定位时发送：

```text
X_MM = -2147483648
Y_MM = -2147483648
```

飞控收到任一无效哨兵值后立即撤销位置有效标志。超过150 ms没有收到
新的CRC正确、坐标有效帧，也撤销位置有效标志。超过300 ms没有收到
结构和CRC正确的帧，判定链路断开。

示例：

```text
X_MM = 1000
Y_MM = -500

AA 55 E8 03 00 00 0C FE FF FF 31 2D 0D 0A
```

飞控实现位于 `UserDriver/CarPoseXyUart.c`。
