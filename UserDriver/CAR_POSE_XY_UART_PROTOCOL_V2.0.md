# 小车单片机 X/Y/起飞标志 → 无线透传 → 飞控 UART 协议 V2.1

V2.1新增起飞标志，使用15字节扩展帧。飞控仍兼容原来的V2.0
14字节X/Y帧；无线模块只做透明传输，飞控从USART1接收原始帧。

## 串口

```text
115200 bit/s
8-N-1
无流控
20 Hz
3.3 V TTL
```

## V2.1扩展15字节帧

| 偏移 | 长度 | 字段 |
|---:|---:|---|
| 0 | 1 | `0xAA` |
| 1 | 1 | `0x56` |
| 2 | 4 | `X_MM`，有符号32位小端 |
| 6 | 4 | `Y_MM`，有符号32位小端 |
| 10 | 1 | `TAKEOFF_FLAG`，只能为`0`或`1` |
| 11 | 2 | CRC16，小端 |
| 13 | 1 | `0x0D` |
| 14 | 1 | `0x0A` |

CRC采用CRC-16/CCITT-FALSE：

```text
Poly   = 0x1021
Init   = 0xFFFF
RefIn  = false
RefOut = false
XorOut = 0x0000
覆盖范围 = frame[2]...frame[10]
```

`TAKEOFF_FLAG`上电默认视为`0`。小车先发送`0`，准备完成后改为`1`；
飞控在CH6任务允许档下启动一次盲飞状态机。任务启动后无需依赖该位持续为
`1`。若需要再次启动，必须先重新发送`0`，再发送`1`。

旧V2.0帧仍按`AA 55 + X/Y + CRC + 0D 0A`共14字节解析，但旧帧没有
起飞权限，收到旧帧时`TAKEOFF_FLAG`按`0`处理。

正常坐标单位为毫米。无有效定位时发送：

```text
X_MM = -2147483648
Y_MM = -2147483648
```

飞控收到任一无效哨兵值后立即撤销位置有效标志。超过150 ms没有收到
新的CRC正确、坐标有效帧，也撤销位置有效标志。超过300 ms没有收到
结构和CRC正确的帧，判定链路断开。

即使X/Y使用上述无效哨兵值，只要V2.1扩展帧的结构、CRC和
`TAKEOFF_FLAG`合法，起飞标志仍会生效，因此小车雷达失效时仍可发送启动命令。

示例：

```text
X_MM = 1000
Y_MM = -500

AA 56 E8 03 00 00 0C FE FF FF 01 EE D4 0D 0A
```

飞控实现位于 `UserDriver/CarPoseXyUart.c`。
