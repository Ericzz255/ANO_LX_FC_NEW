# D题地面站 USART2 遥测协议

## 串口参数

- 飞控：USART2，PD5/TX、PD6/RX
- 参数：500000 bit/s、8 数据位、无校验、1 停止位
- 发送周期：20 Hz
- 多字节整数：小端序

当前版本仅由飞控向 Linux 地面站单向发送遥测，不接收地面站指令。遥测帧格式为：

`AA 55 TYPE LEN PAYLOAD[LEN] CRC16_LO CRC16_HI`

CRC 覆盖 `TYPE`、`LEN` 和完整 Payload。当前接收层负责帧同步、长度检查、CRC 校验、在线时间和错误计数；具体的小车启动、位置和任务命令类型仍需按陆空协同协议单独定义，不包含已删除的禁飞区或路径规划命令。

## 飞行状态帧

固定 22 字节：

| 偏移 | 长度 | 字段 | 说明 |
|---:|---:|---|---|
| 0 | 1 | HEADER1 | 固定 `0xAA` |
| 1 | 1 | HEADER2 | 固定 `0x55` |
| 2 | 1 | TYPE | 固定 `0x01`，飞行状态 |
| 3 | 1 | LENGTH | 固定 `0x10`，Payload 为 16 字节 |
| 4 | 1 | SEQ | 帧序号，0~255 循环 |
| 5 | 1 | MODE | 飞控实际模式 `fc_mode_sta` |
| 6 | 1 | TASK_STEP | 当前任务状态 |
| 7 | 1 | STATUS | 有效性与安全状态位 |
| 8 | 2 | X_CM | 无人机 X，`int16`，单位 cm |
| 10 | 2 | Y_CM | 无人机 Y，`int16`，单位 cm |
| 12 | 2 | HEIGHT_CM | 高度，`uint16`，单位 cm |
| 14 | 2 | BATTERY_CV | 电池电压，`uint16`，单位 0.01 V |
| 16 | 2 | CAR_X_CM | 小车 X，`int16`，单位 cm；无效时为 0 |
| 18 | 2 | CAR_Y_CM | 小车 Y，`int16`，单位 cm；无效时为 0 |
| 20 | 2 | CRC16 | CRC16-CCITT-FALSE，小端序 |

CRC 计算范围为偏移 `[2..19]`，初值 `0xFFFF`、多项式 `0x1021`、不反转、无最终异或。

### STATUS 位

| 位 | 掩码 | 含义 |
|---:|---:|---|
| 0 | `0x01` | 无人机位置有效且最近 300 ms 内有更新 |
| 1 | `0x02` | 最近 500 ms 内收到过有效高度 |
| 2 | `0x04` | 飞控已解锁 |
| 3 | `0x08` | 遥控接收机处于失控保护 |
| 4 | `0x10` | 小车 X/Y 当前有效，最近 150 ms 内收到有效坐标 |
| 5 | `0x20` | 小车链路在线，最近 300 ms 内收到 CRC 正确的帧 |
| 6 | `0x40` | 当前收到的小车 `TAKEOFF_FLAG=1` |

### TASK_STEP

| 值 | 当前含义 |
|---:|---|
| 0 | 空闲 |
| 1 | 已接受小车起飞标志，记录无人机SLAM起点并进入程控模式 |
| 2 | 等待遥控器解锁 |
| 3 | 解锁后等待 2 秒 |
| 4 | 起飞至 100 cm |
| 5 | 进入高度容差后连续定点悬停 3 秒 |
| 6 | 使用无人机SLAM依次飞向B、上半圆、C和D，各航点X/Y容差为±13 cm |
| 7 | 到达D后释放电磁铁，保持100 cm返回绝对坐标`(0,0)`并稳定3秒 |
| 8 | 执行一键降落 |
| 10 | CH6中位安全悬停：保持进入中位瞬间的位置和激光高度 |
