# Linux 地面站 USART2 遥测协议

## 串口参数

- 飞控端：USART2，PD5/TX、PD6/RX
- Linux 板卡：只需连接 RX 和 GND
- 参数：115200 bit/s、8 数据位、无校验、1 停止位
- 发送周期：20 Hz（每 50 ms 一帧）
- 多字节整数：小端序

## 飞行状态帧

固定 24 字节：

| 偏移 | 长度 | 字段 | 说明 |
|---:|---:|---|---|
| 0 | 1 | HEADER1 | 固定 `0xAA` |
| 1 | 1 | HEADER2 | 固定 `0x55` |
| 2 | 1 | TYPE | 固定 `0x01`，飞行状态 |
| 3 | 1 | LENGTH | 固定 `0x12`，Payload 为 18 字节 |
| 4 | 1 | SEQ | 帧序号，0~255循环 |
| 5 | 1 | MODE | 飞控实际模式 `fc_mode_sta` |
| 6 | 1 | TASK_STEP | 自动任务状态机步骤 |
| 7 | 1 | STATUS | 状态位 |
| 8 | 2 | X_CM | SLAM X，`int16`，单位 cm |
| 10 | 2 | Y_CM | SLAM Y，`int16`，单位 cm |
| 12 | 2 | HEIGHT_CM | 测距高度，`uint16`，单位 cm |
| 14 | 2 | VX_CMPS | 飞控估计 X 速度，`int16`，单位 cm/s |
| 16 | 2 | VY_CMPS | 飞控估计 Y 速度，`int16`，单位 cm/s |
| 18 | 2 | WAYPOINT | 界面显示用的当前航点，0~TOTAL |
| 20 | 2 | TOTAL | 规划航点总数 |
| 22 | 2 | CRC16 | CRC16-CCITT-FALSE，小端序 |

CRC 计算范围为偏移 `[2..21]`，参数：

- 初值 `0xFFFF`
- 多项式 `0x1021`
- 不反转
- 无最终异或

### STATUS 位

| 位 | 掩码 | 含义 |
|---:|---:|---|
| 0 | `0x01` | SLAM 坐标有效且最近 300 ms 内有更新 |
| 1 | `0x02` | 高度传感器已连接且工作正常；0 cm也属于可显示数据 |
| 2 | `0x04` | 飞控已解锁 |
| 3 | `0x08` | 已存在完整禁飞区配置（兼容旧任务） |
| 4 | `0x10` | 已生成有效航线 |
| 5 | `0x20` | 遥控器失控保护 |

### TASK_STEP

| 值 | 含义 |
|---:|---|
| 0 | 空闲 |
| 1 | 等待地图、SLAM及航线规划 |
| 2 | 等待遥控器解锁 |
| 3 | 解锁后等待 2 秒 |
| 4 | 发送起飞命令 |
| 5 | 起飞后稳定悬停 |
| 6 | 航点飞行 |
| 7 | 降落 |

## Linux 端换算

- `X(m) = X_CM / 100.0`
- `Y(m) = Y_CM / 100.0`
- `高度(m) = HEIGHT_CM / 100.0`
- `VX(m/s) = VX_CMPS / 100.0`
- `VY(m/s) = VY_CMPS / 100.0`
- 合速度：`sqrt(VX² + VY²)`
- `STATUS & 0x01` 为 0 时，界面应显示 SLAM 无效。
- `STATUS & 0x02` 为 0 时，高度建议显示 `--`。

Linux 串口接收应先搜索连续帧头 `AA 55`，再检查 `TYPE`、`LENGTH` 和 CRC；CRC失败时丢弃一个字节后重新搜索帧头。
