++*-# D题飞控备赛代码说明

本工程正在从上一届网格巡查任务切换到“陆空协同无人机系统（D题）”。已移除固定禁飞区、9×7 网格覆盖、BFS/蛇形路径、航点进度和相关串口命令。

## 当前保留的本题基础

- USART3 接收外部定位坐标，并送入水平位置闭环。
- 高度控制和水平定点控制。
- USART2 以 20 Hz 向 Linux 地面站发送无人机位置、速度、高度、电压、偏航角和任务状态，并解析地面站上行帧、记录链路状态和错误计数。
- USART1 接收 MaixCAM 的 AprilTag 小车靶心跟踪帧，只传结构化数据，不传输图像；支持四码中心和有效对角码中心。
- IOA3/PB0 电磁铁 MOSFET 输出，用于软质物体抛投。
- 一键起飞、降落和飞控状态接口。

## 当前自动流程

`FcSrc/User_Task.c` 是安全的备赛骨架。CH6 高位仅用于台架调试：

1. 等待有效位置并进入程控模式。
2. 等待遥控器解锁。
3. 起飞至 50 cm。
4. 进入高度容差后稳定悬停 3 秒。
5. 保持起飞点横向坐标，直接向机头前方移动 200 cm（X+），同时搜索目标图案。
6. 前飞途中一旦收到有效 MaixCAM 目标，切换为视觉速度闭环，使无人机保持在图案上空。
7. 目标在中心容差内连续保持约 3.5 秒后进入一键降落，完成任务。
8. 视觉跟随期间若暂时丢失目标或偏出中心，中心计时清零；丢失时立即清零视觉速度和积分，并在当前位置悬停等待重新识别。
9. 若前飞到终点仍未发现目标，则将 IOA3/PB0 拉低释放物体，随后进入一键降落流程。

CH6 低位保留为台架安全降落。比赛正式流程不能依赖遥控器触发；后续要改为小车一键启动后通过无线链路触发。

## 下一步需要实现

- 小车启动命令和小车位置/状态的无线协议。
- 识别小车并形成相对位置、航向和速度近似同步的伴飞控制。
- D 点前完成抛投的动作状态与失败保护。
- 动态降落、平台停留 5 秒、再次起飞。
- 返回 H 点并平稳降落。
- 地面站同时显示无人机、小车位置及“伴飞、抛投、降落、起飞”等文字状态。
