++*-# D题飞控备赛代码说明

本工程正在从上一届网格巡查任务切换到“陆空协同无人机系统（D题）”。已移除固定禁飞区、9×7 网格覆盖、BFS/蛇形路径、航点进度和相关串口命令。

## 当前保留的本题基础

- USART3 接收外部定位坐标，并送入水平位置闭环。
- 高度控制和水平定点控制。
- USART2 以 500000 bit/s、20 Hz 向 Linux 地面站发送无人机位置、高度、电压、任务状态和小车 X/Y 坐标，并解析地面站上行帧、记录链路状态和错误计数。
- USART1 以 115200 bit/s 接收小车 N10P/Cartographer V2.0纯X/Y固定14字节帧，校验帧尾和CRC；任一坐标为 `-2147483648` 时立即判无效，并执行150 ms控制超时与300 ms链路超时。
- 匿名上位机用户数据诊断：`USERDATA6/7` 显示当前有效小车X/Y坐标（cm，无效时为0），`USERDATA5=1` 表示合法帧链路在线，`USERDATA3=1` 表示当前小车位姿可用于跟踪。
- IOA3/PB0 电磁铁 MOSFET 输出，用于软质物体抛投。
- 一键起飞、降落和飞控状态接口。

## 当前自动流程

`FcSrc/User_Task.c` 是安全的备赛骨架。CH6 高位仅用于台架调试：

1. 在小车仍位于启动点时，记录无人机SLAM起点和第一帧有效小车坐标，然后进入程控模式。
2. 等待遥控器解锁。
3. 起飞至 80 cm。
4. 进入高度容差后稳定悬停 3 秒。
5. 等待一帧满足状态和年龄要求的小车位姿，将小车相对启动点的位移加上初始偏置 `X=+250 mm、Y=-375 mm`，再映射到无人机SLAM绝对目标坐标。
6. 每收到一个新序号的小车位姿，持续更新水平目标点；小车 Yaw、Vx、Vy 和 YawRate 暂不参与控制。
7. 小车离开起点100 cm后再次返回起点30 cm范围内，或小车移动超过10 cm后坐标在±1 cm内连续3秒不变，均触发返航；冻结最后的跟随目标，等待无人机进入目标点10 cm范围。
8. 无人机完成整圈后释放电磁铁，保持80 cm返回SLAM绝对坐标 `(0,0)`，在返航点±5 cm内稳定1秒后降落。
9. 超过 150 ms 没有有效新位姿时，退出跟随并锁定无人机当前 SLAM 坐标悬停；重新收到有效新帧后继续跟随。

CH6 高位运行台架任务；CH6 中位和低位都会记录切换瞬间的位置与激光高度并持续定高定点悬停。完整任务结束后的自动降落不受影响。比赛正式流程不能依赖遥控器触发；后续要改为小车一键启动后通过无线链路触发。

坐标映射假设双方都是“X向前、Y向左”且坐标轴平行。由于无人机水平控制使用整数厘米，右侧37.5 cm会就近表示为Y方向约-38 cm。台架测试时必须在小车尚未离开规定启动位置前拉高CH6，否则第一帧会被误认为小车起点。

## 下一步需要实现

- 在实机上核对无人机与小车的场地坐标原点、X/Y方向和毫米/厘米换算。
- 实飞调整坐标跟随的位置环参数，并根据需要加入小车速度前馈。
- 定义抛投触发条件；当前跟随状态不会自动抛投或自动降落。
- D 点前完成抛投的动作状态与失败保护。
- 动态降落、平台停留 5 秒、再次起飞。
- 返回 H 点并平稳降落。
- 地面站同时显示无人机、小车位置及“伴飞、抛投、降落、起飞”等文字状态。
