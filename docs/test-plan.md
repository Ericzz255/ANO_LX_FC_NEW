# 验证与测试计划

目标是为每个关键结论留下可复查证据。测试按“源码/构建 → 台架 → 桨叶拆除整机 → 受控试飞”的顺序推进。

## 证据记录模板

每次测试至少记录：

- 日期、测试人员和环境；
- Git 提交或工作区 diff；
- Keil 工程、编译器版本和构建日志；
- 飞控、机载计算平台和小车所烧录版本；
- 接线、电压、串口参数和坐标系；
- 输入条件、期望结果、实际结果；
- 十六进制帧、USERDATA/遥测曲线、视频或示波器截图；
- 结论：通过、失败或因证据不足未验证。

## A. 构建与静态检查

| ID | 检查 | 通过条件 |
|---|---|---|
| A1 | Keil 完整构建 | 0 error；warning 有解释 |

| ID | 注入 | 期望结果 |
|---|---|---|
| B1 | USART3 黄金 SLAM 帧 | X/Y 按有符号大端正确更新，USERDATA4 在资格确认后为 1 |
| B2 | USART3 坏 CRC | 坐标不更新，错误帧不刷新有效时间 |
| B3 | USART3 截断和乱序字节 | 解析器重新同步，不产生伪坐标 |

| B6 | 断开 USART3 RX >300 ms | 水平故障锁存，自动任务进入降落路径 |
| B7 | USART1 V2.1 黄金帧 | X/Y、链路、坐标有效性和启动标志分别正确 |

## C. 任务状态机台架测试

| ID | 场景 | 期望结果 |
|---|---|---|
| C1 | CH6 未允许时拉高启动标志 | 不启动自动任务 |
| C2 | 启动标志 0→1，但 SLAM 无效 | 停留在等待定位，不执行起飞 |
| C3 | 定位有效但未人工解锁 | 停留在状态 2，不发送解锁命令 |
| C4 | 启动标志持续为 1 | 只启动一次；任务重置后不能立即重复启动 |
| C5 | 启动标志先回 0 再回 1 | 重新获得一次启动资格 |
| C6 | 模拟航点逐点到达 | 航点索引 0..7 单调前进并进入返航 |
| C7 | 航点冻结超过 20 s | 进入状态 8 |
| C8 | 注入围栏外坐标 | 进入状态 8，停止水平任务输出 |
| C9 | 返航点未稳定满 3 s | 不提前降落；离开容差后稳定计时清零 |

## D. 桨叶拆除整机测试

| ID | 检查 | 通过条件 |
|---|---|---|
| D1 | 机体前后左右移动 | SLAM、光流和控制坐标方向一致 |
| D2 | 抬升/降低机体 | 高度符号、单位和超时正确 |

| D5 | 同时运行三条串口 | 无明显丢帧、队列堆积或控制周期抖动 |

## E. 受控试飞递进

1. 仅人工飞行，验证定位和高度遥测，不启用自动任务。
2. 自动起飞后原点悬停，暂不执行航线。
3. 单个低速短距离航点。
4. B 点直飞。
5. 完整 B-C-D 航段，不安装载荷。
6. 加入抛投动作，但人工接管返航。
7. 完整自动任务。
8. 在安全高度和场地条件允许时，逐项验证定位中断与任务超时保护。

任何阶段出现坐标方向、控制发散、电源跌落、模式异常或无法可靠人工接管时，都应停止进入下一阶段。

## 建议量化指标

- SLAM 实际更新率、丢帧率和最大连续中断；
- 端到端位置延迟的平均值、P95 和最大值；
- 50 Hz 控制周期抖动；
- 悬停 X/Y 均方根误差和最大误差；
- 航点首次进入时间、稳定时间和超调；
- 完整任务成功率；
- 故障注入到进入安全状态的响应时间。
